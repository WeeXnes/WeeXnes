## Projects

| | |
| :-- | :-- |
| **[ClyoCloud](https://github.com/WeeXnes/ClyoCloud)** | Self-hosted cloud storage and media server: files, sharing, streaming, wallpapers with ComfyUI generation, and companion apps for Android and the desktop. `Nuxt` `Nitro` `Kotlin` `Electron` |
| **[OpenNGFW](https://github.com/WeeXnes/OpenNGFW)** | Minimal Linux firmware for the Netgear R6300v2 router: Linux 6.6 LTS, WireGuard, USB persistence and its own package manager. `Buildroot` `Linux` |
| **[ngpkg](https://github.com/WeeXnes/ngpkg)** | The package manager for OpenNGFW: bash, nano, htop, git, ufw and more on the router, with no runtime dependencies. `V` `C` |
| **[OpenProStreetClient](https://github.com/WeeXnes/OpenProStreetClient)** | Game plugin for OpenProStreet servers (Need for Speed: ProStreet): encrypted login, race results and leaderboards. `C++` |
| **[razerd](https://github.com/WeeXnes/razerd)** | Linux control suite for Razer peripherals, built on OpenRazer, with a monochrome native UI. `Electron` `TypeScript` |
| **[akkod](https://github.com/WeeXnes/akkod)** | Configuration tool for the Akko 5075S (QMK/VIA): keymap, layers, knob and lighting, on Linux and Windows. `Electron` `TypeScript` |
| **[OPLNova](https://github.com/WeeXnes/OPLNova)** | Modern alternative to OPL Manager for managing PS2 games with Open PS2 Loader. `C#` `.NET` |

More, including the Minecraft and ProStreet projects, is on **[code.weexnes.dev](https://code.weexnes.dev)**.
